# DualCross agent (first agent, report Sec. 3)

Code of the first system, kept for reference. It is not used by the PTCGNet agent in `ptcg/`.

- `code/`: feature parser and card tracker, `PTCGDualCrossNet` (relational cross-attention transformer),
  BC / IQL / PPO / WiSE-FT training scripts, the light search agent (`search_agent.py`),
  deck tournament and evaluation scripts, Kaggle submission packaging.
- `decks/`: decklists used in DualCross experiments.
- `results/`: DualCross benchmark summaries (e.g. `approach_ac_benchmark.json`, the 9-agent local ladder in Appendix C of the report).

The scripts were written as a flat folder and expect to be run from it, with the competition engine (`cg/`)
and the derived card tables (`card_static_table.npy`, `card_text_embeddings*.npy`, regenerated by
`card_static_table.py` and `card_text_encoder.py`) next to them. Checkpoints and parsed replays are not included.
